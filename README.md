## What is ArcticWorks Atlas?

Atlas is a free, open-source offline maps app built on [OpenStreetMap](https://www.openstreetmap.org) with the ArcticWorks design language. A fork of [CoMaps](https://codeberg.org/comaps/comaps), which itself is a fork of Organic Maps, originally based on Maps.ME.

Download maps once and navigate without a connection. No tracking, no ads, no data collection.

## Features

- 🗺️ Detailed offline maps with places not available on Google Maps
- 🥾 Outdoor mode with hiking trails, campsites, water sources, peaks, contour lines
- 🚴 Walking paths and cycleways
- 📍 Points of interest: restaurants, gas stations, hotels, shops, sights
- 🔍 Search by name, address, or category
- 🧭 Voice-guided navigation for walking, cycling, and driving
- ⭐ Bookmarks for favorite places
- 📚 Offline Wikipedia articles
- 🚇 Subway transit layer and directions
- 📼 Track recording
- 💾 Bookmark and track export/import in KML, KMZ, GPX
- 🌙 Dark mode
- ✏️ Built-in editor to improve map data for everyone
- 🚗 Android Auto and CarPlay support
